# Portfolio · David Medeiros

Case studies with live demos of data, CRM and AI systems I built in production, rebuilt here on synthetic data.

| Case | What it shows |
|---|---|
| Data Trust Monitor | Reconciliation against a source of truth, fraud detection, daily invariants |
| Segmentation & Holdout Lab | Behavioral segmentation, circuit breakers, incrementality with control groups |
| BI Agent with Evals | LLM-routed SQL, deterministic number validation, gold-set evals, cost per question |

## Stack
Next.js (static export) · TypeScript · Vitest · GitHub Actions

## Run locally
npm ci && npm run dev

## Note on data
All data is synthetic and generated with a fixed seed. The original systems were proprietary; no code, schema or data from them is included.
